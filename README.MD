# BASIC PRACTICE - REACT JS

This is a practice from REACTJS module for my Full Stack Web Development Course!

The goal is about to learn REACT. This time the project will consist in the following:

### This Repository will be:

An app that will show and manage dinamically a panel to admin a sort of Pokemons.

- Main page with navigate buttons and list of pokemons
  - Create pokemon button
    - Form-type panel to create a new pokemon with name, url, height, weight, type, and a button to create it.
  - Contact.
    - Small card to show info about me.
  - List with ID, Name, URL, see Details, and add to favorites
    - Card with details of the selected pokemon
    - Delete button
    - modify button
      - Form-tyoe with inputs (only name able to edit)
      - save button
      - cancel button
    - cancel button to go back
